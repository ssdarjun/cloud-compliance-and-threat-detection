# Cloud Compliance & Automated Threat Detection

Infrastructure security monitoring scripts, alerting rules, and compliance configurations designed to track real-time security events, unauthorized API calls, and cloud resource drift.

## Monitoring Capabilities
- **Native Threat Intelligence:** Configuration templates for AWS GuardDuty and AWS Security Hub integration.
- **Audit Logging:** Centralized CloudTrail log monitoring configured with integrity validation.
- **Automated Alerting:** EventBridge rules coupled with SNS/Lambda webhooks to instantly notify security teams of high-severity anomalies (e.g., security group modification to `0.0.0.0/0`).
